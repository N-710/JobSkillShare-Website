COURSE DETAILS

Course Overview

The Cloud Administrator | Basics course is designed to provide a comprehensive introduction to cloud computing, with an emphasis on Microsoft Azure.

This course is perfect for those new to cloud technology or IT professionals seeking to enhance their skills in managing and deploying cloud solutions.

Participants will explore core cloud concepts, learn about architectural frameworks, and get accustomed to various service models.

You'll delve into essential Azure services, covering networking, storage, identity management, and more, through hands-on labs.

This course not only introduces cloud fundamentals but also equips learners with practical skills for real-world scenarios, such as resource monitoring, automation, and troubleshooting within a cloud environment.

LEARNING OUTCOMES

What You’ll Learn

  • Understand core cloud concepts and deployment models.
  • Manage Azure resources, including virtual machines and networking.
  • Implement cloud security, compliance, and best practices.
  • Monitor cloud resources and optimize performance.
  • Perform automation using PowerShell and CLI tools.
