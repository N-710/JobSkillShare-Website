What is a Systems Engineer?

Build a Solid Foundation in Systems Engineering

The Systems Engineer Certificate Program is a comprehensive pathway for learners pursuing careers in systems engineering and administration, covering network and systems administration, server management, cloud services, Linux, and PowerShell.

Each course builds on the last, taking you from foundational IT concepts to practical server, cloud, Linux, and automation skills.

OUTCOMES

Skills You'll Build

Build a practical, hands-on skill set across networking, server administration, cloud, Linux, and automation — the core toolkit of a working systems engineer.

Network Configuration & Security

Configure networks, switching, and routing, and implement network security measures.

Windows Server Administration

Install, configure, and manage Windows Server environments and Active Directory.

Cloud Administration with Azure

Manage cloud deployments, storage, compute, and identity access using Microsoft Azure.

Linux System Configuration

Configure Linux operating systems, manage file systems, and control access permissions.

DHCP & DNS Deployment

Deploy and manage DHCP and DNS services within Windows Server environments.

PowerShell & Automation

Write PowerShell scripts to automate administrative tasks and hybrid system management.
