COURSE DETAILS

Course Overview

Amazon Web Services (AWS) is a leading cloud service provider offering a range of services including Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).

Our comprehensive AWS Cloud Administrator Fundamentals course guides you through the foundational aspects of AWS, using hands-on labs to reinforce learning through practical application.

A Hands-On Learning Experience

This course includes modules designed to build your understanding of core AWS services. From fundamental concepts to practical applications, you'll gain the skills needed to navigate AWS environments confidently.

The labs focus on practical, real-world scenarios using an AWS subscription tailored for learning.

Key Modules

  • AWS Fundamentals: Start with the basics of cloud concepts and become familiar with AWS infrastructure.
  • VPC and Subnet Routing: Explore AWS regions, availability zones and network configurations.
  • EC2 and Storage Options: Work with Elastic Compute and EBS storage solutions while learning snapshot management and restoration.
  • Security and Administration: Manage security groups and use AWS backup capabilities for resource protection.
  • Load Balancing and Database Management: Understand Network Load Balancers and relational database services within the AWS ecosystem.

By the end of this course, you will have a foundational understanding of essential AWS services and how to apply this knowledge to real-world administrative tasks.

LEARNING OUTCOMES

What You’ll Learn

  • Understand fundamental AWS cloud concepts and services.
  • Configure AWS Virtual Private Clouds (VPC) and manage subnets.
  • Utilize EC2 for scalable compute resources and manage Elastic Block Store (EBS) volumes.
  • Implement AWS security best practices and manage instances using security groups.
  • Leverage AWS S3 storage services for data storage and retrieval.
  • Administer RDS databases and execute backup strategies.
  • Deploy and manage network load balancers for efficient resource distribution.
