COURSE DETAILS

Course Overview

Welcome to the "Modern IT Support Training: Part 1 | A+ (220-1102)" course. This entry-level program is designed for individuals eager to begin a career in IT support. While we recommend taking our updated course for the latest resources and labs, this course remains valuable for learning foundational IT concepts through video-based content.

What You Will Learn

This course focuses on key areas necessary for IT support, including setting up workstations, installing and managing software, establishing network connections, and ensuring security and preventative maintenance. You will gain practical knowledge on configuring both Windows and Linux operating systems, implementing network security, and managing authentication and authorization processes.

Skills Development

Participants will learn to identify Windows OS editions, troubleshoot software issues, and utilize both command line and GUI tools for system management. The course also covers mobile OS troubleshooting, managing network settings, and understanding IT operational procedures.

LEARNING OUTCOMES

What You’ll Learn

  • Set up and configure Windows and Linux systems.
  • Troubleshoot and resolve software issues.
  • Establish and manage network connections.
  • Identify and mitigate security risks.
