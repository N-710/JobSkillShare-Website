COURSE DETAILS

Course Overview

CompTIA Security+ Training (SY0-701) Part 2 is designed to build on foundational cybersecurity concepts, providing hands-on experience in network security analysis and mitigation strategies. This course focuses on practical application of the skills required to assess and secure network infrastructures.

Throughout the course, you will engage in exercises that deepen your understanding of network vulnerabilities and proactive defense mechanisms. You'll delve into cryptographic solutions, threat vector analysis, security architecture modeling, vulnerability management, monitoring and enterprise infrastructure hardening.

This course complements the theoretical knowledge gained in Part 1, focusing on real-world applications and practical lab exercises for the CompTIA Security+ certification exam (SY0-701).

LEARNING OUTCOMES

What You’ll Learn

  • Analyze network infrastructure for security vulnerabilities.
  • Implement cryptographic solutions and digital signatures.
  • Identify and mitigate threat vectors and attack surfaces.
  • Conduct vulnerability assessments and apply monitoring techniques.
  • Harden security architecture and enterprise infrastructures.
